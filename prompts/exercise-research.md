- `displayName` — 운동의 **널리 통용되는 한국어 명칭**. 기구와 그립/각도가 이름의 일부라면 함께 씁니다 (`바벨 벤치프레스`, `랫풀다운 (와이드 그립)`)
- `targetMuscles` — 주로 쓰는 근육. **아래 목록의 값만** 사용합니다. 1개 이상, 보통 2~4개
- `equipmentType` — 사용 기구. 아래 목록의 값 하나
- `mechanic` — 아래 목록의 값 하나
- `forceType` — 아래 목록의 값 하나

## 규칙

### 1. ⚠️ 목록에 없는 값을 만들지 않습니다

`코어`·`전신`·`복합근` 처럼 위 목록에 없는 값은 **저장되지 않고 버려집니다.** 그러면 자극부위가 비어 근육맵이 아무것도 칠하지 못합니다 — 화면은 정상으로 보이고 값만 없는, 늦게 발견되는 결함입니다.

가장 가까운 값으로 **바꿔서** 답하세요. 예: 플랭크의 주 부위는 `abdominals` 입니다.

### 2. ⚠️ 널리 통용되는 이름을 씁니다

이 이름이 **여러 사람이 같은 운동으로 만나는 열쇠**입니다 (`FR-11-A-09`).

- 헬스장·기록 앱에서 실제로 쓰는 이름을 씁니다
- 같은 운동의 변형은 **괄호로 구분**합니다 (`랫풀다운 (와이드 그립)`)
- 브랜드 기구명을 이름에 넣지 않습니다 (`핵스쿼트` ✅ / `사이벡스 핵스쿼트` ❌) — 기구 제조사는 사람마다 다릅니다

### 3. ⚠️ 같은 운동을 여러 후보로 쪼개지 않습니다

`벤치프레스` 와 `바벨 벤치프레스` 를 둘 다 내지 마세요. **기구가 이름의 일부인 쪽 하나만** 냅니다 (`바벨 벤치프레스`). 쪼개면 도감이 갈라져 같은 운동을 하는 사람들이 서로 다른 항목으로 흩어집니다.

단, **자극이 실제로 다른 변형은 별개**입니다 — `인클라인 벤치프레스`(윗가슴)와 `바벨 벤치프레스`는 다른 운동으로 봅니다.

### 4. 대표적인 운동을 우선합니다

요청 건수를 못 채워도 됩니다. 확실한 것만 답하세요 — 0건이어도 정상입니다.

### 5. 형식

- 값에 앞뒤 공백·따옴표·괄호 주석을 넣지 않습니다 (운동명의 그립 표기는 예외)
- 설명·비고를 넣지 않습니다

## 출력 형식

**JSON 배열 하나만** 출력합니다. 코드펜스·설명·머리말 없이.

```
[{"displayName":"바벨 벤치프레스","targetMuscles":["chest","triceps","shoulders"],"equipmentType":"barbell","mechanic":"compound","forceType":"push"}]
```

확실한 후보가 없으면 빈 배열 `[]` 을 출력합니다.
